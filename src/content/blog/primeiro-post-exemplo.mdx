# Primeiro post de exemplo

Este arquivo existe para servir de modelo real. Para criar outro post, copie o
`_template.mdx`, troque os metadados no topo e escreva o texto aqui embaixo.

## O que pode virar post

O blog pode receber pensamentos soltos, revisoes de jogos, filmes, livros,
aprendizados de desenvolvimento, notas de projeto ou qualquer texto que voce
queira guardar no site.

Como o conteudo fica no repositorio, cada publicacao tambem fica versionada no
Git. Isso deixa o comeco simples e evita precisar de login, banco de dados ou
painel administrativo antes da hora.
